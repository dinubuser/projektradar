Die Projektsperre

Wer zu viele Projekte anfängt, kann sich selbst eine Pause verordnen. Für einen Zeitraum keine neuen Projekte, bis die gewählten Hürden erreicht sind.

Tor geschlossen bis 30.11.

Erfundenes Beispiel mit zwei Hürden.

  • Hochbeet fertig1 von 1, Schlüssel gefunden
  • 100 Mailadressen gesammelt37 von 100
  • Ein Tor, Schlüssel als Hürden. Du legst bis zu 6 Hürden fest. Jede braucht eine Zahl, zum Beispiel Ziel 100, Stand 37. Hürden ohne Zahl lassen sich nicht abhaken.
  • Ein Enddatum. Sind alle Schlüssel gefunden oder ist das Datum vorbei, öffnet sich das Tor. Die Sperre gilt bis und mit dem Enddatum.
  • Sie blockiert nie. Mit Claude Code fragt sie nur nach, bevor ein neues Projekt angelegt wird: «Die Sperre läuft bis …, trotzdem anlegen?» Bei Ja wird das Projekt als Ausnahme markiert. Du entscheidest.
  • Ehrlich dazu: Die Sperre ist eine Erinnerung an dich selbst, kein Schloss. Skills springen nicht immer von selbst an. Darum bietet /projektsperre an, eine Zeile in deine globale CLAUDE.md zu schreiben, aber nur, wenn du Ja sagst.

Drei Wege, es auszuprobieren

Ohne Installation

ChatGPT

Öffne das Projektradar im Browser und klicke auf «ChatGPT-Prompt kopieren». Füge den Prompt in ChatGPT im Modus Work ein. ChatGPT fragt nach deinen Projektordnern und füllt die Seite.

Mac, Claude Code

Claude Code

Ein Befehl im Terminal. Claude liest deine Code-Ordner, Notizen und Automationen und trägt die Projekte selbst ein.

curl -fsSL https://raw.githubusercontent.com/dinubuser/projektradar/main/install.sh | bash

Erster Stand, Desktop

Obsidian-Plugin

Das Projektradar als Reiter direkt in Obsidian. Du kopierst die Dateien des Plugins in deinen Vault und schaltest es in den Community-Plugins ein. Die Schritte stehen in der README.

Ehrlich dazu: Es gibt automatische Tests, aber das Plugin lief noch nicht in einem echten Obsidian. Probiere es zuerst in einem leeren Vault aus.

Datenschutz

Alles bleibt auf deinem Gerät

Das Projektradar schickt nichts an einen Server und braucht kein Konto. Beim ChatGPT-Weg liegen die Daten im Browser, beim Claude-Code-Weg in der Datei selbst.

Zwei Dinge, die du wissen musst

  • Die Prozentzahlen sind Schätzungen. Prüfe sie, bevor du dich darauf verlässt.
  • Deine Datei enthält Ordnerpfade und Projektnamen. Gib sie nicht weiter.
